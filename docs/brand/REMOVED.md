# ArtCraft marks removed

This fork of FilmCraft does not ship the ArtCraft wordmark or symbol.

`LICENSE-brand.txt` (kept here so the terms stay with the tree) allows those marks only
unmodified and only for official FilmCraft. Forks must remove them. The PNG and SVG files
that were in this directory in upstream commit `8309f21` are not in this fork.

You may say, in plain text, that the editor is based on FilmCraft by the ArtCraft team.
See `NOTICE`.
